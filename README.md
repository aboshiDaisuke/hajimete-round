# はじめてのラウンド

ゴルフ初心者が約3か月（12週）でコースデビューするための練習ウェブアプリ。

## 開き方

`index.html` をブラウザ（Chrome / Safari / Edge）で開くだけでも動きます。
ファイルを直接開く場合、3D表示の Three.js は CDN から読み込むため通信が必要です。
PC で開くと、スマホ幅のアプリ画面が中央に表示されます。

### スマホでアプリとして使う（PWA）

`index.html` と `css/`・`js/`・`assets/`・`vendor/`・`manifest.webmanifest`・`sw.js` を同じ構成のままHTTPSで配信します。
ホームの「アプリとして使う」、または設定の同名カードから追加方法を確認できます。

- iPhone / iPad：Safari の共有ボタン →「ホーム画面に追加」。表示される場合は「Webアプリとして開く」をONにして追加。
- Android：対応ブラウザで設定の「ホーム画面に追加する」ボタン、またはブラウザのメニューから追加。
- 追加したアイコンから起動すると、アドレスバーのないアプリ画面になります。ノッチやホームインジケーターの余白にも対応しています。

初回に約12MBのアプリ本体を保存します。設定に「オフラインの準備ができました」と表示された後は、
通信がなくても再起動・練習・記録・3D表示・ゲームを使えます。3Dのライブラリは `vendor/three/` に同梱しています（Three.js 0.170.0、MITライセンス）。
外部フォントを読み込めない場合は端末の標準書体を使います。記録はこの端末内に保存し、他の端末との同期は行いません。

更新は裏で一式を保存し終えてから、アプリの画面をすべて閉じて開き直すと反映されます。
練習中に自動リロードしません。更新の取得に失敗した場合も、前の版と保存済みの記録を維持します。
配信ファイルを変更した際は、公開前に `python3 tools/build_pwa.py` でオフライン保存一覧と版を更新してください。

PWAの登録・インストールにはHTTPS（開発用は `http://localhost` / `http://127.0.0.1`）が必要です。
`file://`、スマホからの通常のHTTP接続、単独HTMLの `dist/artifact.html` ではPWAとして登録しません。
ローカル確認は `python3 -m http.server 8765 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8765` を開きます。

## できること

最初に、Blenderで作った小さなゴルフコースと男女のキャラが迎えるタイトル画面が開きます。
左右にドラッグしてコースを見渡したり、キャラをタップしてあいさつできます。
キャラを選んで「さあ、はじめよう」を押すと、初回はニックネームと練習・デビューの日程を設定してホームへ進みます。
次回以降は「つづきからはじめる」で、保存済みの記録を引き継ぎます。「まずは練習内容を見てみる」から練習メニューを確認することもできます。
ホーム上部の旗ボタンからタイトルに戻れます。`#home` などのリンクからは、その画面を直接開けます。

起動・ホームの3Dコースにはクラブハウス、芝のストライプ、池、バンカー、木々、旗を配置しています。
キャラの呼吸・まばたき・あいさつ、揺れる旗と流れる雲をThree.jsで描画します。
読み込み中や3Dが使えない環境ではBlenderでレンダリングした静止画を表示し、開始ボタンはそのまま使えます。
画面外・別タブでは描画を止め、端末の「動きを減らす」設定にも対応しています。

| タブ | 内容 |
|---|---|
| ホーム | デビューまでの日数と今週のテーマ、時間と場所（5分／15分／練習場）に合った今日の練習、途中保存からの再開、応援する3Dキャラ、ペース調整、今週の練習、週の振り返り、デビューへの準備。ゲーム・読み物は折りたたみから開く |
| 練習 | 12週プログラム（1週＝1ホール）、ドリル図鑑（20種・図解つき）、テンポ練習（音つき） |
| プレー | 3クリックショットのゲーム：ショートラウンド（3ホール）／全9ホール、ニアピン、ドラコン、パター距離感。コース3つ（グリーンヒルズ・レイクサイド・シーサイドリンクス）と天気（晴れ・夕焼け・くもり・雨）を選べ、ラウンドのスコアは「ラウンドの記録」に残る |
| 学ぶ | 3Dコース図鑑、ゴルフの歴史、うんちく、クイズ、用語集、ルールとマナー、デビュー準備、クラブの基本 |
| マイ | レベル・XP、バッジ、着せ替え（ボール・ウェア）、練習カレンダー（13週）とこれまでの合計、練習ログと週ごとの練習時間グラフ |

### 今日の練習から、次回の練習へ

- ホームと練習タブの「今日の練習を始める」で、今週の12週プログラムに沿ったメニューを順番に案内します。5分は1メニュー、15分は最大2メニュー、練習場は40分を目安に最大3メニュー（デビュー週は1メニュー・20分の軽めの練習）。練習場所に合わない内容やゴルフゲームは、このおすすめに混ぜません。
- 各メニューは「説明 → 準備 → 練習」の順。既存の図解とやり方を表示し、必要な道具と練習場所を確認してから始めます。任意のタイマーと回数・球数カウンターを使えます。
- 「保存してホームへ」で中断できます。画面移動・別タブ・終了時にはタイマーを止め、途中の手順、回数、時間、振り返りの入力をこの端末へ保存します。戻ったあとは手動でタイマーを再開します。
- 最後に「取り組めた／難しかった／今回は見送り」と、実際の場所・時間・メモ・次に意識することを入力。既存の練習ログとカレンダーに反映します。タイマーだけで週の目標を達成扱いにはせず、「週の目標まで取り組めた」に本人がチェックした項目だけを達成にします。すべて見送った場合は練習ログとXPを増やしません。
- 難しかったメニューと、週の振り返りで選んだ復習を、次回の場所が合うときに優先します。同じ内容に「取り組めた」と記録すると、難しかった内容として固定し続けません。
- 「デビューへの準備」は、ショット・パターとアプローチ・ルールとマナー・当日の準備を本人が振り返るチェックです。XPやゲーム成績による実力判定ではありません。
- デビューまで21日以内は、当日の準備への入口をホームに表示します。「デビュー準備」にはコース名・集合時間・スタート時間・集合場所や行き方の自動保存メモがあります。

### キャラクター

- みんなのGOLF風の男女2人のゴルファーから、練習・ゲームで使うキャラを選べる（「プレー」「マイ」の「使うキャラクターを選ぶ」）。「いつもの服」のほか、レベルで増えるシャツの色にも変えられる
- 設定画は Codex（画像生成）で作ったオリジナルキャラ（`tools/sheets/`）。その3面図（正面・横・背面）から、Blender で体の形・骨・アニメーションを作り、設定画そのものをテクスチャとして貼っている。顔だけは、同じキャラの高解像度の顔アップ（`tools/sheets/head_*.png`）に差し替えて精細にしている
- 動き：待機（息づかい・クラブのちょんちょん・まばたき）、スイング、パット、喜び（バーディー・カップイン・ナイスショットなど）、落ち込み（OB・池・ミス）。表情も切り替わる
- 「プレー」「マイ」の大きなキャラ表示は、設定画と同じ姿勢で立ち、ドラッグで回せて、タップすると喜ぶ

キャラを作り直すとき：

```
python3 tools/sheet_model.py female                        # 設定画 → 体の形・テクスチャ（tools/build/）
python3 tools/face_states.py female                        # 表情（まばたき・喜び・落ち込み）の絵 → assets/golfer-female-face.js
CHARACTER=female blender -b -P tools/blender_golfer.py     # 骨・アニメーション → assets/golfer-female.glb と -glb.js
```

（`tools/sheet_model.py` には scikit-image・scipy・Pillow が必要。設定画ごとの関節位置などは `tools/characters/*.json`。）

### BGM

スーパーファミコン風のオリジナル曲を、Web Audioで演奏します（音源・再生制御は `js/bgm.js`、新曲・編曲は `js/bgm-score.js`）。
32kHzのサンプル、柔らかいブラスとフルート、エレピ、マリンバ、ストリングス、ベースとドラムを組み合わせ、こもったステレオエコーを加えています。実機を再現するエミュレーターではなく、16bit時代のゲーム音楽を参考にした音源です。
タイトルのメロディは、結果画面の曲にも登場します。曲には複数のセクションがあり、楽器や伴奏を変えて展開します。

| 場面 | 曲 |
|---|---|
| タイトル・初回設定 | きょうの、はじめの一打（108BPM・32小節） |
| ホーム・プレー・練習・学ぶ・マイ | 木もれ日のクラブハウス（94BPM・24小節のボサノバ） |
| ショートラウンド | フェアウェイ・クルージング（128BPM・32小節） |
| ニアピン・ドラコン | ピンをねらえ！（152BPM・16小節） |
| パター距離感 | グリーンのそよ風（80BPM・16小節） |
| ラウンド・チャレンジの結果 | ナイスラウンド！（92BPM・16小節） |

バーディー・カップイン・ミス・レベルアップには、それぞれ短いジングルがあります。
画面をタップするとBGMが始まり、タイトル下部の音楽ボタンからも聴けます。スピーカーボタンや設定でON/OFFを切り替え、設定で音量を調整できます。音量とON/OFFは保存します。
テンポ練習中はBGMを止めます。画面を閉じる・タブを切り替えると一時停止し、戻ると続きを再生します。曲が変わるときは短いフェードでつなぎ、ジングルの間はBGMの音量を下げます。
試聴用MP3は `assets/audio/first-tee.mp3` と `assets/audio/clubhouse.mp3`。アプリ本体の演奏にはMP3を使わないため、音楽ファイルのダウンロードを待たずに演奏できます。

### ゲームと練習のつながり

- 練習メニューの達成・練習記録・クイズ・デイリーミッション・バッジで XP がたまり、レベルが上がる
- レベルが上がると、ゲームのゴルファーのパワーとナイスショットのゾーン幅が上がり、着せ替えとコース（Lv.3でレイクサイド、Lv.5でリンクスと全9ホール）が増える
- 雨の日は風が強く（×1.6）、ボールが転がりにくくなる（×0.7）
- ゲームの中でも OB（1打罰で打ち直し）・池（1打罰でドロップ）・パーの2倍でギブアップなど、実際のルールどおりに進む

進捗や記録はブラウザの localStorage に保存されます（端末ごと）。

```

css/style.css         デザイン（ライト／ダーク対応）
js/data.js            コンテンツ（12週プログラム・ドリル・歴史・うんちく・クイズ・用語・ルール）
js/app.js             画面の切り替え・保存・各画面の描画
js/pwa.js             ホーム画面への追加案内・オフライン準備状況
sw.js                 アプリ本体の保存・オフライン配信・更新
manifest.webmanifest  アプリ名・アイコン・起動方法
vendor/three/         配信版の3Dライブラリ（MIT、0.170.0）
js/practice-flow.js   練習の案内・途中保存・振り返り・準備の自己確認
js/scene3d.js         3Dコース（地形・芝・池・木・旗・解説ポイント）
js/lobby3d.js         起動・ホームの3Dジオラマ、キャラ選択・あいさつ・カメラ操作
js/putting.js         パター距離感ゲーム
js/tempo.js           テンポ練習
js/game.js            ラウンドゲーム（3クリックショット・弾道・転がり・スイング同期）
js/bgm.js             BGM（Web Audio で演奏するオリジナル曲とファンファーレ）
js/bgm-score.js       タイトル・クラブハウス・結果の楽譜と、既存曲の編曲
assets/golfer-glb.js  Blender で作ったゴルファー（体・服・クラブ・スイング／パットのアニメーション）
assets/ball-glb.js    Blender で作ったディンプル付きボール（GLB を埋め込み）
assets/*.png, *.jpg   Blender でレンダリングしたアイコンとヒーロー画像
tools/blender_assets.py  ボール・アイコン・ヒーロー画像を作る Blender スクリプト
tools/blender_lobby.py   起動コースと読み込み中の静止画を作る Blender スクリプト
tools/face_states.py    表情の絵（目・口）を作る
tools/blender_golfer.py  ゴルファーを作る Blender スクリプト（-- check でポーズ確認画像も）
tools/build_artifact.py  1枚のHTMLにまとめる（公開用 → dist/artifact.html）
tools/build_pwa.py       オフライン保存一覧・配信バージョンの更新
```

## 素材を作り直す

起動・ホームのジオラマを作り直す場合：

```
blender -b -P tools/blender_lobby.py
```

`assets/lobby.glb`、直接開くための埋め込みデータ `assets/lobby-glb.js`、
読み込み中の画像 `assets/lobby-poster.png` を生成します。編集用のシーンは `tools/build/lobby.blend` に保存します。

```
blender -b -P tools/blender_golfer.py
node -e "const b=require('fs').readFileSync('assets/golfer.glb');require('fs').writeFileSync('assets/golfer-glb.js','window.GOLFER_GLB_BASE64=\"'+b.toString('base64')+'\";')"
blender -b -P tools/blender_assets.py
python3 -c "import base64;b=open('assets/ball.glb','rb').read();open('assets/ball-glb.js','w').write('window.BALL_GLB_BASE64=\"'+base64.b64encode(b).decode()+'\";')"
```

コンテンツを増やしたいときは `js/data.js` を編集してください。

### 無理なく続けるための仕組み
- 1週のメニューは「6割できれば目安クリア」。全部やらなくていいことを画面で伝える
- 遅れたときは「今日からもう1週間つづける」「ひとつ前の週からやり直す」で、その週が今日から始まるように開始日とデビュー日をうしろへずらす（設定でいつでも戻せる）
- 7日以上あいたら「おかえりなさい」を出す。練習した日は、メニュー・記録・テンポ・パター・ドリルの「やった」から数える

### 練習フローの確認

Playwright と Chromium を用意した環境で、ローカルサーバーを起動してから実行できます。

```sh
GOLF_URL=http://127.0.0.1:8765 node tools/test_practice.cjs
```

既存の保存データの引き継ぎ、練習の中断と再開、振り返りの下書き、明示的な達成チェック、見送り、復習候補、12週と3つの時間・場所の組み合わせ、当日の予定、スマホ幅での表示を確認します。Chromium の場所を指定する場合は `GOLF_BROWSER_PATH`、画面画像を保存する場合は `GOLF_SCREENSHOT_DIR` を設定できます。テストは専用のブラウザプロファイルを使い、普段の記録は変更しません。

### PWAの確認

Playwright と Chromium を用意し、`node tools/test_pwa.cjs` を実行します。
専用サーバーを自動で立ち上げ、ホーム画面への追加案内、320px幅、通信を切った後の起動・3D・ゲーム・練習再開、
更新待ち中のデータ保持、更新失敗時の復旧、サブディレクトリ配信を確認します。
`GOLF_BROWSER_PATH` と `GOLF_SCREENSHOT_DIR` も使用できます。OSの実際の追加操作は実機で確認してください。
