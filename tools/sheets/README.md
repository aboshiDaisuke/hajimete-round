# キャラ設定画（3面図）

Codex（画像生成）で作ったオリジナルのキャラクターです。`female.png` / `male.png`。
背景は無地（女性は明るいグレー、男性は中間グレー）、正面・横（左向き）・背面が同じ大きさ・同じ地面の高さで並んでいること。
作り直すときは、次のようなプロンプトを Codex に渡します（`codex exec "..."`）。

- 共通：「みんなのGOLF（Everybody's Golf WORLD）風の、約6.5頭身・すらっとした若いゴルファー。なめらかな陰影のアニメCG、黒い輪郭線なし、大きな表情豊かな目。正面・横（左向き）・背面の3面図、A ポーズ、無地の背景、影なし、文字・ロゴなし」
- 女性：茶色のボブ、ピンクの帯のホワイトバイザー、ノースリーブのグリーンのジップポロ、白いプリーツスカート、白×グリーンのシューズ、左手に白いグローブ、赤い腕時計
- 男性：黒髪、オレンジのつばの白いキャップ、オレンジの半袖ポロ、ベージュのスリムなパンツ、白×オレンジのシューズ、左手に白いグローブ、黒いリストバンド

`head_female.png` / `head_male.png` は、上の設定画を参照画像にして Codex に作らせた「同じキャラの顔のアップ（正面・肩まで）」です（`codex exec -i 参照画像 - < プロンプト`）。背景は無地の中間グレー。`tools/characters/*.json` の `hires_head` に、顔アップの中の目・口の位置を書いてあります。
